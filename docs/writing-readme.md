# Writing the README

The root README should answer:

1. What Taskman is (one short paragraph)
2. Requirements (Python / uv)
3. Setup (`uv sync`)
4. How to run (`uv run uvicorn app.main:app --reload`)
5. Where to try it (`/docs`)
6. Link to deeper docs under `docs/`

Keep it short. Details and process notes belong in `docs/`, not in the README.
